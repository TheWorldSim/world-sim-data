

# Processing

* Download the data from: https://www.gov.uk/government/publications/renewable-energy-planning-database-quarterly-extract
* Place as a file named REPD_publication_Q1_2026.csv (or whatever it is called) in this directory
* Update the script in process.py to have the new file name
* Run process.py to generate the processed data file solar_farms_uk_Q1_2026.csv
